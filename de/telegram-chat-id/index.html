  • Die Chat ID ist die feste Nummer, mit der Telegram einen Chat erkennt: positiv bei Nutzern, negativ bei Gruppen und Kanälen.
  • Am sichersten findest du sie mit deinem eigenen Bot: Nachricht schicken, getUpdates aufrufen, Wert chat.id ablesen.

Die Telegram Chat ID ist die Nummer, mit der Telegram einen Chat eindeutig erkennt. Bei Nutzern ist sie positiv, bei Gruppen negativ, und Kanäle und Supergruppen beginnen im Format der Bot API mit -100. Am sichersten findest du sie mit deinem eigenen Bot: ihm eine Nachricht schicken, getUpdates aufrufen und den Wert chat.id ablesen.

Was ist eine Telegram Chat ID?

Jeder Chat in Telegram hat eine feste Nummer: dein Konto, jede Gruppe, jeder Kanal, jeder Bot. Gebraucht wird sie vor allem von Programmen. Ein Bot, der Benachrichtigungen in eine Gruppe schicken soll, oder ein Werkzeug wie ein Smart-Home-System braucht die ID des Ziel-Chats, sonst weiß es nicht, wohin.

Die Bot API beschreibt die ID als eindeutige Kennung des Chats. Sie kann mehr als 32 Bit haben, aber höchstens 52, deshalb sollte ein Programm sie als 64-Bit-Ganzzahl speichern. Manche Programmiersprachen verfälschen so große Zahlen sonst still.

Deine eigene Nummer heißt meist Telegram-ID oder User-ID. Sie gehört zur selben Reihe wie die IDs von Gruppen und Kanälen. MergeVerse, das Spiel zu diesem Blog (ab 18, nicht mit Telegram verbunden), nutzt laut seinen FAQ diese Telegram-ID auch als ID im Spiel.

So sehen Chat IDs aus

Die Zahlenbereiche stehen in der Entwicklerdoku zu den Bot-API-IDs (Stand 22. November 2026):

Chat Vorzeichen Bereich im Bot-API-Format
Nutzer und Bots positiv 1 bis 1.099.511.627.775
normale Gruppe negativ -1 bis -999.999.999.999
Supergruppe und Kanal negativ, beginnt mit -100 -1.000.000.000.001 bis -1.997.852.516.352

Aus dem Vorzeichen und der Länge erkennst du also, um welche Art von Chat es geht. Eine positive Zahl ist immer ein Nutzer oder ein Bot.

Warum Kanal-IDs mit -100 beginnen

Intern zählt Telegram Nutzer, Gruppen und Kanäle in getrennten Reihen, die sich überschneiden. Eine Gruppe und ein Kanal könnten intern dieselbe Nummer haben. Die Bot API macht daraus eine einzige Reihe ohne Doppel:

  • Bei Nutzern bleibt die Nummer, wie sie ist.
  • Bei normalen Gruppen wird sie negativ.
  • Bei Supergruppen und Kanälen rechnet die Bot API -(1.000.000.000.000 + interne ID).

Ein Beispiel: Die interne Kanal-ID 1234567890 wird zu -1001234567890. Bei zehnstelligen internen IDs sieht das so aus, als würde man einfach -100 voranstellen. Die Doku lässt aber interne Kanal-IDs bis 997.852.516.352 zu. Hat eine ID mehr als zehn Stellen, stimmt die Abkürzung 'einfach -100 davor' nicht mehr, die Rechnung schon.

Methode 1: mit deinem eigenen Bot und getUpdates

Das geht ohne fremde Dienste. Du brauchst einen Bot; wie du ihn bei @BotFather anlegst, steht in Telegram-Bot erstellen.

  1. Schick deinem Bot im Einzelchat eine Nachricht. Für eine Gruppe fügst du den Bot hinzu und schickst dort einen Befehl an ihn, etwa /start@NameDeinesBots. Für einen Kanal fügst du den Bot hinzu und veröffentlichst einen Beitrag.
  2. Öffne im Browser api.telegram.org/bot/getUpdates und setz statt den Token deines Bots ein.
  3. Such in der Antwort nach "chat" und darin nach "id". Bei Beiträgen in Kanälen steht der Chat unter "channel_post".
  4. Notiere die Zahl samt Minuszeichen.

Verwechsle dabei nicht chat.id mit from.id. In einer Gruppe ist from.id die Nummer der Person, die geschrieben hat, chat.id die Nummer der Gruppe.

Bleibt die Antwort leer, liegt es meist an einem von drei Dingen. Ist für den Bot ein Webhook eingerichtet, funktioniert getUpdates laut Bot API nicht. Telegram hebt Updates höchstens 24 Stunden auf, alte Nachrichten tauchen also nicht mehr auf. Und in Gruppen läuft jeder Bot standardmäßig im Privatsphäre-Modus: Er sieht dann nur Befehle, die an ihn gerichtet sind (wie /start@NameDeinesBots), und Antworten auf seine Nachrichten. Bots, die Admin sind, bekommen alle Nachrichten.

Zum Token: Wer ihn kennt, steuert deinen Bot. Die Adresse mit dem Token landet im Browserverlauf. Mach das also nur auf deinem eigenen Gerät, und wenn der Token doch irgendwo aufgetaucht ist, lass dir bei @BotFather mit /token einen neuen geben.

Methode 2: aus dem Link einer Nachricht

Für Kanäle und Supergruppen mit privatem Link sieht ein Link zu einer Nachricht laut Entwicklerdoku so aus: t.me/c//. Die erste Zahl nach /c/ ist die interne ID des Kanals oder der Supergruppe, die zweite die Nummer der Nachricht.

Aus t.me/c/1234567890/25 wird also die Chat ID -1001234567890, gerechnet wie oben. Für einen Bot brauchst du diese Form mit Minus. Öffentliche Kanäle und Gruppen haben dagegen Links mit ihrem Benutzernamen, t.me//; dort steht keine Zahl. Für sie akzeptiert die Bot API laut Doku statt der ID auch den Benutzernamen im Format @username.

Methode 3: experimentelle Option in Telegram Desktop

Telegram Desktop hat seit Version 4.11.1 vom 29. Oktober 2023 eine experimentelle Option, die die ID unter dem Info-Text im Profil anzeigt. Im Änderungsprotokoll heißt sie 'show-peer-id-below-about'. Die experimentellen Einstellungen liegen dort laut Protokoll unter Einstellungen > Erweitert. Wie die Option in der deutschen Oberfläche genau beschriftet ist, haben wir in keiner offiziellen Quelle gefunden. Experimentelle Optionen kann Telegram jederzeit ändern oder entfernen.

Wenn sich die ID ändert: Gruppe wird Supergruppe

Eine normale Gruppe kann zur Supergruppe werden. Dann bekommt sie eine neue ID im -100-Format. Die Bot API meldet das mit einer Dienstnachricht: Das Feld migrate_to_chat_id enthält die neue ID der Supergruppe, migrate_from_chat_id in der Supergruppe die alte.

Speichert dein Programm die ID einer Gruppe, lohnt es sich, sie aus diesen beiden Feldern zu aktualisieren.

Brauche ich einen ID-Bot?

Viele Anleitungen schicken dich zu fremden Bots, die dir deine ID nennen. Nötig ist das nicht, Methode 1 kommt ohne Dritte aus. Telegram schreibt in seinen deutschen FAQ, du sollst jeden Bot wie einen Fremden behandeln. Holst du einen fremden Bot in eine Gruppe und hat er den Privatsphäre-Modus abgeschaltet, sieht er alle Nachrichten; in der Mitgliederliste steht dann 'Zugriff auf Nachrichten'.

Mit der Nummer allein kann eine App laut Entwicklerdoku nicht mit dir in Kontakt treten; dafür braucht sie einen zusätzlichen Zugriffsschlüssel. Wer dich finden und anschreiben kann, regeln dein Telegram-Benutzername und die Privatsphäre-Einstellungen, etwa in Telegram Nummer verbergen. Was andere sonst in deinem Profil sehen, erklärt Telegram Status.

Häufige Fragen

Wie finde ich die Chat ID einer Telegram-Gruppe?

Füge deinen eigenen Bot zur Gruppe hinzu und schick dort einen Befehl an ihn, etwa /start@NameDeinesBots. Dann rufst du im Browser api.telegram.org/bot<Token>/getUpdates auf und liest den Wert chat.id ab. Bei Gruppen ist er negativ.

Warum beginnt die Chat ID mit -100?

So rechnet die Bot API Kanal- und Supergruppen-IDs um: Sie addiert 1.000.000.000.000 zur internen ID und macht das Ergebnis negativ. Bei den üblichen zehnstelligen internen IDs sieht das aus, als stünde -100 davor.

Ist die Chat ID dasselbe wie der Benutzername?

Nein. Den Benutzernamen wählst du selbst und kannst ihn ändern oder löschen. Die Chat ID vergibt Telegram, und sie bleibt gleich. Für öffentliche Kanäle akzeptiert die Bot API aber auch den Benutzernamen im Format @username statt der Zahl.

Warum zeigt getUpdates nichts an?

Meist aus einem von drei Gründen: Für den Bot ist ein Webhook eingerichtet, dann funktioniert getUpdates laut Bot API nicht; die Nachricht ist älter als 24 Stunden; oder der Bot läuft in der Gruppe im Privatsphäre-Modus und hat deine Nachricht gar nicht bekommen.

Kann jemand mit meiner Chat ID etwas anstellen?

Die Nummer allein öffnet keinen Chat mit dir. Trotzdem gibt es keinen Grund, sie fremden Bots oder Websites zu schicken. Wer dich finden kann, steuerst du über Benutzername und Privatsphäre-Einstellungen.
