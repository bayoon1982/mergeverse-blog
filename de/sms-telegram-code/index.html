  • Der Chat 'Verifizierungscodes' ist nur für Codes fremder Dienste; dein eigener Telegram-Code steht nie dort.

Der Telegram-Code kommt oft gar nicht per SMS. Warst du kürzlich auf einem anderen Gerät angemeldet, schickt Telegram den Anmeldecode zuerst dorthin, in den Chat 'Telegram' mit blauem Haken. Schau also auf Handy, Tablet und Computer nach. Kommt dort nichts, prüf die Nummer im internationalen Format, warte auf den nächsten Zustellweg und schreib notfalls an sms@telegram.org.

Alles hier stammt aus den deutschen und englischen FAQ von telegram.org und der Entwicklerdokumentation auf core.telegram.org, gelesen am 24. November 2026. Diese Seite steht in keiner Verbindung zu Telegram.

Warum kommt der Telegram-Code nicht per SMS?

Die deutschen FAQ nennen zuerst diesen Fall: Hast du Telegram kurz zuvor auf einem anderen Gerät genutzt, kann Telegram den Anmeldecode per Telegram statt per SMS senden. Laut Entwicklerdoku geht die Nachricht an alle anderen angemeldeten Sitzungen.

Die Entwicklerdoku zeigt, wie viele Wege es inzwischen gibt. Telegram entscheidet selbst, wie der Code kommt. Möglich sind:

  • eine Nachricht an alle anderen angemeldeten Sitzungen;
  • eine SMS, manchmal nur mit einem Wort oder einer Wortfolge statt Ziffern;
  • ein Anruf, bei dem eine Computerstimme den Code ansagt;
  • ein kurzer Anruf, der sofort auflegt; dann sind die letzten Ziffern der anrufenden Nummer der Code;
  • eine E-Mail an eine hinterlegte Anmelde-Adresse.

Kommt der Code nicht innerhalb einer Wartezeit an, kann laut Doku ein anderer Weg folgen, den Telegram vorher festlegt. Es lohnt sich also, kurz zu warten, statt die Nummer immer wieder neu einzugeben.

Wo landet der Code in Telegram?

Es gibt zwei Chats, die leicht verwechselt werden.

Chat Was dort ankommt Weitergeben?
'Telegram' (blauer Haken) dein Anmeldecode für das Telegram-Konto niemals
'Verifizierungscodes' Codes fremder Dienste, bei denen du dich mit deiner Nummer anmeldest, etwa Webseiten, Apps oder Marktplätze nur in den Dienst, den du selbst angefordert hast

Laut FAQ entscheiden die fremden Dienste selbst, ob sie ihren Code per SMS oder über Telegram schicken; Telegram kann das nicht steuern. Suchst du also eine SMS von deiner Bank-App oder einem Shop und findest sie nicht, steht der Code vielleicht im Chat 'Verifizierungscodes'.

Erst prüfen: Nummer und Gerät

Bevor du an Telegram schreibst, geh diese Liste durch:

  1. Öffne Telegram auf jedem Gerät, auf dem du angemeldet sein könntest, und schau in den Chat 'Telegram'.
  2. Gib die Nummer im internationalen Format ein. Die deutschen FAQ nennen als Beispiel +491713920099 für die deutsche Nummer 0171-3920099: Ländervorwahl davor, die erste Null weg.
  3. Nutze eine Handynummer. Festnetznummern unterstützt Telegram laut FAQ nicht.
  4. Prüf, ob du die richtige App nutzt. Laut Entwicklerdoku bekommen in manchen Fällen nur die offiziellen Handy-Apps einen Code per SMS oder Anruf; inoffizielle Apps und Computer-Apps melden sich dann über die anderen Wege an.
  5. Warte etwas ab, bevor du einen neuen Code anforderst; danach kann der Code auf einem anderen Weg kommen.

Hast du die Nummer gewechselt, ist das ein eigenes Problem. Die FAQ warnt: Der Code per Telegram ist kein Ersatz für eine aktuelle Handynummer. Wer die alte Nummer nicht in den Einstellungen geändert hat, kann den Zugriff auf sein Konto dauerhaft verlieren.

Code per Anruf oder E-Mail

Der Anruf ist nicht immer verfügbar. Die englische FAQ schreibt, dass Codes per Anruf bei manchen Mobilfunkanbietern fehlen oder die zweistufige Bestätigung voraussetzen. Die deutsche Fassung ist strenger und nennt den Anruf nur für Konten mit zweistufiger Bestätigung. Einschalten kannst du sie unter Einstellungen → Privatsphäre und Sicherheit → Zweistufige Bestätigung.

Die E-Mail kommt laut Entwicklerdoku ins Spiel, wenn du dich oft genug anmeldest. Dann fragt Telegram nach einer Adresse, an die künftig der Anmeldecode geht, und bestätigt sie vorher. Wer diese Adresse eingerichtet hat, findet den Code im Postfach.

In manchen Ländern sind SMS-Codes sehr teuer. Für diesen Fall beschreibt die Doku, dass offizielle Apps zum Anmelden ein Telegram-Premium-Abo verlangen können. Was Premium sonst bringt, steht in Telegram Premium.

Ganz ohne SMS: Passkeys

Die SMS ist nicht der einzige Weg: Mit Passkeys geht es ohne. Laut deutschen FAQ legst du auf einem Gerät, auf dem du schon angemeldet bist, einen Passkey an. Danach meldest du dich an wie beim Entsperren deines Handys, mit PIN, Fingerabdruck oder Face ID. Die FAQ nennt das ausdrücklich als Ausweg, wenn du unterwegs bist oder keinen SMS-Empfang hast.

Verwalten kannst du Passkeys unter Einstellungen → Privatsphäre und Sicherheit → Passkeys. Ein Passwortmanager wie der iCloud-Schlüsselbund oder der Google Passwortmanager kann den Passkey sichern, falls du das Gerät wechselst. Eine SMS kannst du trotzdem weiter anfordern, deshalb soll die Nummer im Konto aktuell sein und dir gehören.

Code bekommen, ohne ihn anzufordern

Das wirkt beunruhigend, ist aber meist harmlos. Bei einem Code im Chat 'Verifizierungscodes' schreibt Telegram: Wahrscheinlich hat jemand deine Nummer bei einem anderen Dienst eingegeben, vielleicht aus Versehen. Dein Telegram-Konto ist sicher. Tippe auf den Code und wähle 'Melden', mehr musst du nicht tun.

Kommt ein Anmeldecode für dein Telegram-Konto, den du nicht angefordert hast, gilt eine Regel ohne Ausnahme: nicht weitergeben. Login-Codes sollen laut FAQ niemals geteilt werden, auch nicht mit anderen Diensten oder Apps. Die deutschen FAQ ergänzen: Behandle jeden Bot wie einen Fremden und gib keine Anmeldecodes weiter. Mini Apps sind Erweiterungen von Bots, mehr dazu in Telegram Mini Apps.

Gegen fremde Anmeldeversuche hilft die zweistufige Bestätigung. Mit ihr brauchst du zum Anmelden den SMS-Code und dein Passwort. Hinterlege dazu eine E-Mail-Adresse für den Fall, dass du das Passwort vergisst, und schütze dieses Postfach ebenfalls gut.

Wenn gar nichts hilft

Die deutschen FAQ nennen die Adresse sms@telegram.org für Probleme mit Registrierung oder Anmeldung. Schreib dazu deine Handynummer im internationalen Format und den Namen deines Mobilfunkanbieters. Ist dein Konto gesperrt, erscheint beim Anmelden ein Hinweis; dann tippst du auf den Knopf 'HILFE'.

Von Webseiten, die fremde oder virtuelle Nummern für SMS-Codes anbieten, raten wir ab. Dein Konto hängt an der Nummer. Die FAQ rät zu einer aktuellen Nummer, die dir gehört; wer eine geänderte Nummer nicht eingetragen hat, kann den Zugriff dauerhaft verlieren. Inaktive Konten löscht Telegram standardmäßig nach 18 Monaten. Wer seine Nummer vor anderen verbergen will, findet den Weg in Telegram-Nummer verbergen; ohne Nummer erreichbar bist du über einen Telegram-Benutzernamen. Häufige Fragen

Warum bekomme ich keine SMS mit dem Telegram-Code?

Meist, weil Telegram den Code gar nicht per SMS schickt. Wenn du kürzlich auf einem anderen Gerät angemeldet warst, kommt er dort im Chat 'Telegram' mit blauem Haken an. Prüf also zuerst deine anderen Geräte.

Kann ich den Telegram-Code per Anruf bekommen?

Manchmal. Laut FAQ ist der Anruf bei einigen Mobilfunkanbietern nicht verfügbar oder setzt voraus, dass die zweistufige Bestätigung eingeschaltet ist. Laut Entwicklerdoku wählt Telegram selbst, auf welchem Weg der Code kommt; nach einer Wartezeit kann ein anderer Weg folgen.

Was ist der Chat „Verifizierungscodes“ bei Telegram?

Ein verifizierter Chat, in dem fremde Dienste ihre Bestätigungscodes über Telegram schicken, etwa eine Webseite oder ein Marktplatz. Login-Codes für dein Telegram-Konto kommen dort nie an, sondern im Chat 'Telegram'.

Ich habe einen Telegram-Code bekommen, ohne ihn anzufordern. Was nun?

Nicht weitergeben. Steht der Code im Chat 'Verifizierungscodes', hat laut FAQ wahrscheinlich jemand deine Nummer bei einem fremden Dienst eingegeben, und dein Telegram-Konto ist sicher; tippe auf den Code und wähle 'Melden'. Ein unerwarteter Anmeldecode im Chat 'Telegram' ist ein Grund, die zweistufige Bestätigung einzuschalten.

Wohin schreibe ich, wenn der Code gar nicht kommt?

Laut den deutschen FAQ an sms@telegram.org. Gib deine Handynummer und den Namen deines Mobilfunkanbieters an. Ist dein Konto gesperrt, erscheint beim Anmelden ein Hinweis mit dem Knopf 'HILFE'.
